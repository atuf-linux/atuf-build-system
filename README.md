# atuf-build-system

This repository contains the necessary configuration files and scripts to automatically generate a bootable ISO image of Atuf Linux.

The process primarily involves:
1.  Starting with a base KDE neon image.
2.  Adding custom repositories for packages in `atuf-core`.
3.  Installing packages and configuring the live environment.
4.  Generating the final `.iso` file.
